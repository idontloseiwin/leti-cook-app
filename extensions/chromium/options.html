Connect to Leti Cook

Add a channel from YouTube using the button next to Subscribe.

Use the same address you open in this browser. For a remote server, keep your SSH tunnel running.

Allow access when the browser asks, then sign in to Leti Cook if needed. Return to YouTube and reload the page.

What access does this use?

The extension reads the channel link beside YouTube's Subscribe button. It adds a channel only when you click its button.

It uses your existing Leti Cook session. It stores only this address, not your password or YouTube API key. Browser permission may cover other ports on this local host; the extension uses only the address you save.
